支付流程

供应商端
平台端
客户端

一、平台 ↔ 客户 · 支付节点对照（预付款 + 尾款）

节点 A · 预付款 + 节点 B · 尾款 客户 → 平台 两次支付 · 预付款可选
客户结算单：草稿 → 待审核账单 → 已审核 → 待付款 → 已付款 → 已收款（终态）
订单级支付状态：待支付 → 部分支付 → 全额支付 → 已收款（终态）
步 节点 客户侧 平台侧 单据 / 状态
1 节点 A
预付款		 客户创建并提交采购订单 平台填写【预收款】→【选择是否要预付款】→ 填写预付款比例 → 【生成预付款结算单】（不需要预付款时不生成此单据，直接进入尾款） 平台销售订单状态：待确认
客户采购订单 / 平台销售订单：待支付
预付款结算单：草稿
2 —（平台内部步骤，客户未介入） 销售 / 会计 核对金额、维护账单日期 → 【推送】→ 单据进入平台账单池 预付款结算单：草稿 → 待审核账单
3 —（平台内部步骤，客户未介入） 会计 账单详情 → 【平台审核】→ 账单进入「已审核」，可推送付款单 预付款结算单：待审核账单 → 已审核
4 采购订单详情页 / 我的账单 → 查看预付款结算单，显示「待付款」 【推送付款单】→ 推送给客户 预付款结算单：已审核 → 待付款
客户采购订单 / 平台销售订单：待支付
5 结算单页 【在线支付（通联）】支付预付款金额 → 付款完成 等待付款到账 预付款结算单：待付款 → 已付款
客户采购订单 / 平台销售订单：待支付 → 部分支付
6 结算单显示「已付款」 核对到账（可查看账户余额）→ 【确认收款】→ 结算单置为已收款 预付款结算单：已收款（客户侧显示“已付款”）
客户采购订单 / 平台销售订单：部分支付（预付款已收款、尾款未收款）
7 节点 B
尾款		 客户全部确认收货后 平台侧出现【尾款】按钮 → 【生成尾款结算单】 平台销售订单状态：收货完成
尾款结算单：草稿
8 —（平台内部步骤，客户未介入） 销售 / 会计 核对金额、维护账单日期 → 【推送】→ 单据进入平台账单池 尾款结算单：草稿 → 待审核账单
9 —（平台内部步骤，客户未介入） 会计 账单详情 → 【平台审核】→ 账单进入「已审核」，可推送付款单 尾款结算单：待审核账单 → 已审核
10 采购订单详情页 / 我的账单 → 查看尾款结算单，显示「待付款」 【推送付款单】→ 推送给客户 尾款结算单：已审核 → 待付款
客户采购订单 / 平台销售订单：部分支付（维持，预付款已收款、尾款未收款）
11 结算单页 【在线支付（通联）】支付尾款：足额 / 少付（少付需填差异原因 + 上传凭证）→ 付款完成 等待付款到账；收到差额 → 【标记差额】 尾款结算单：待付款 → 已付款
客户采购订单 / 平台销售订单：部分支付 → 全额支付
12 结算单显示「已付款」 核对到账（可查看账户余额）→ 【确认收款】→ 采购订单结清 尾款结算单：已收款（客户侧显示“已付款”）
客户采购订单 / 平台销售订单：已收款（客户侧显示“已付款”）
业务状态：已结清

二、平台 ↔ 供应商 · 支付节点对照（平台付款给供应商）

供应商结算与平台审核 ＋ 平台付款与供应商收款 平台 → 供应商
步 节点 供应商侧 平台侧 单据 / 状态
1 节点C
结算与审核		 客户确认收货后 → 销售订单 → 【创建结算】→ 生成草稿结算单 —（平台此时未介入） 供应商结算单：草稿
2 核对金额、维护账单日期 → 【推送到平台】 会计 > 供应商 > 账单 出现待处理记录 供应商结算单：待审核账单
3 —（供应商不参与开票，只等收款） 会计 账单详情 → 【平台审核】→ 账单进入「已审核」，可推送付款单 供应商结算单：待审核账单 → 已审核
4 等待付款（结算单显示“待收款”） 账单页维护支付人 → 【推送付款单】→ 推给平台出纳
支付节点从这一步开始		 供应商结算单：待付款（供应商侧显示“待收款”）
平台采购订单支付状态：待支付
5 等待付款到账 【在线支付（通联）】支付 → 【创建付款】 供应商结算单：已付款（供应商侧显示“已付款”）
平台采购订单支付状态：部分支付 / 全额支付
6 结算单显示“已付款”，可查看支付凭证 / 付款单详情 → 确认收款 与供应商对账 → 结算单置为终态 供应商结算单：已收款（终态）
平台采购订单支付状态：已付款（终态）
业务状态：平台采购订单 / 供应商销售订单 → 已完成
