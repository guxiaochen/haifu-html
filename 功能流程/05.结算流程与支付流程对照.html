结算流程 原方案 供应商 ↔ 平台、平台 ↔ 客户 · 两两对照

一、平台 ↔ 客户、供应商 ↔ 平台结算的文档流程还原

平台 ↔ 客户
两层状态：客户结算单（预付款 / 尾款各一张，共用 6 步）＋ 订单级支付状态（订单级总态，4 步）。
客户结算单：草稿 → 待审核账单 → 已审核 → 待付款 → 已付款 → 已收款（终态）
订单级支付状态：待支付 → 部分支付 → 全额支付 → 已收款（终态）
两侧叫法：同一张单，平台侧显示「已收款」、客户侧显示「已付款」，中间状态两侧一致。
节点 A / 节点 B 各走一遍上述 6 步：节点 A 由平台点【预收款】发起（预付款可选）；节点 B 在全部确认收货后由平台点【尾款】发起。客户结算单不推给平台出纳，【推送付款单】只推给客户，付款由客户在线支付（通联）完成，平台侧只做【确认收款】。
步 平台侧（平台手册 §3.6 · 客户结算） 客户侧（客户手册 §3.7） 单据 / 状态
1 节点 A
预付款		 —（平台内部步骤，客户未介入） 采购订单提交后，平台点【预收款】→【选择是否要预付款】→ 填写预付款比例 → 【生成预付款结算单】（不需要预付款时不生成此单据，直接进入尾款） 预付款结算单：草稿
2 —（平台内部步骤，客户未介入） 销售 / 会计 核对金额、维护账单日期 → 【推送】→ 单据进入平台账单池 预付款结算单：草稿 → 待审核账单
3 —（平台内部步骤，客户未介入） 会计 账单详情 → 【平台审核】→ 账单进入「已审核」，可推送付款单 预付款结算单：待审核账单 → 已审核
4 采购订单详情页 / 我的账单 → 查看预付款结算单，显示「待付款」 【推送付款单】→ 推送给客户 预付款结算单：已审核 → 待付款
客户采购订单 / 平台销售订单：待支付
5 结算单页 【在线支付（通联）】支付预付款金额 → 付款完成 等待付款到账 预付款结算单：待付款 → 已付款
客户采购订单 / 平台销售订单：待支付 → 部分支付
6 结算单显示「已付款」 核对到账（可查看账户余额）→ 【确认收款】→ 结算单置为已收款 预付款结算单：已收款（终态，客户侧显示“已付款”）
客户采购订单 / 平台销售订单：部分支付（预付款已收款、尾款未收款）
7 节点 B
尾款		 —（平台内部步骤，客户未介入） 全部确认收货后，平台侧出现【尾款】按钮 → 【生成尾款结算单】 尾款结算单：草稿
8 —（平台内部步骤，客户未介入） 销售 / 会计 核对金额、维护账单日期 → 【推送】→ 单据进入平台账单池 尾款结算单：草稿 → 待审核账单
9 —（平台内部步骤，客户未介入） 会计 账单详情 → 【平台审核】→ 账单进入「已审核」，可推送付款单 尾款结算单：待审核账单 → 已审核
10 采购订单详情页 / 我的账单 → 查看尾款结算单，显示「待付款」 【推送付款单】→ 推送给客户 尾款结算单：已审核 → 待付款
客户采购订单 / 平台销售订单：部分支付（维持，预付款已收款、尾款未收款）
11 结算单页 【在线支付（通联）】支付尾款：足额 / 少付（少付需填差异原因 + 上传凭证）→ 付款完成 等待付款到账；收到差额 → 【标记差额】 尾款结算单：待付款 → 已付款
客户采购订单 / 平台销售订单：部分支付 → 全额支付
12 结算单显示「已付款」 核对到账（可查看账户余额）→ 【确认收款】→ 采购订单结清 尾款结算单：已收款（终态，客户侧显示“已付款”）
客户采购订单 / 平台销售订单：已收款（终态；客户侧显示“已付款”）
业务状态：已结清
供应商 ↔ 平台
段一的全部动作由供应商发起账单、平台审核与付款完成。
单据上：一张平台采购单 = 一张供应商账单 = 一张供应商销售订单。
关键时序：供应商开账 → 推送平台 → 平台审核 → 供应商开票 → 平台两确认（业务+财务）→ 平台出纳拆分票据 → 平台创建付款 → 供应商账单落地。
步 供应商侧（供应商手册 3.7） 平台侧（平台手册 3.6 · 供应商结算） 单据 / 状态
1 客户确认收货后，进入销售订单 →【创建结算】→ 生成草稿账单 —（平台此时未介入） 供应商账单：草稿
2 核对金额、维护账单日期 →【推送到平台】 会计 > 供应商 > 账单 出现待处理记录 供应商账单：待审核账单
3 等待 账单详情 →【平台审核】 供应商账单：已审核（供应商手册称"待过账"）
4 状态变"待过账"，出现【添加税票】→ 维护发票号 / 类别 / 开票日期 + 上传附件 →【确认】 等待供应商推税票 供应商账单：已审核
5 【确认并推送平台】 账单页顶部出现【税票】→ 税票列表 → 税票详情 销售发票：待审核；销项票：已开票
6 等待 税票详情 →【平台确认】（业务侧） 销售发票：业务已确认
7 等待 税票详情 →【财务确认】→ 税票状态"有效" 销项票：已审核；销售发票：有效
8 等待 返回账单页 → 维护支付人 →【推送付款单】（文档原误写"推送贷款单"）→ 推给平台出纳 供应商账单：待付款
9 等待 出纳【拆分票据】→ 维护处置方式 / 处置日期 + 上传新票据附件 →【确认】 供应链金融票据：拆分完成
10 等待 上传支付凭证 →【支付】→ 支付页 → 维护日记账、供应链金融票据 →【创建付款】 供应商账单：已付款（平台手册称"已支"）
11 结算单状态显示"已支"，可查看支付凭证；点【付款】查看付款单详情 — 供应商账单：已收款（终态）
⚠ 流程问题：
① 客户账单的"创建"动作在平台手册中完全没有描述（既没有"创建客户账单"，也没有"推送客户账单"步骤）；
② 客户侧没有"审核账单"动作（文档无）；
③ 客户侧没有"付款"按钮（由段三票据到期还款实现，供应链票据在采购订单时已确认取消）。
支付流程 支付改动版 平台 ↔ 客户（预付款 / 尾款）· 平台 ↔ 供应商（支付节点）

一、平台 ↔ 客户 · 支付节点对照（预付款 + 尾款）

节点 A · 预付款 + 节点 B · 尾款 客户 → 平台 两次支付 · 预付款可选
两层状态：客户结算单（预付款 / 尾款各一张，共用 5 步）＋ 采购订单级支付状态（订单级总态，4 步）。
客户结算单：草稿 → 待审核 → 已审核 → 待付款 → 已收款（终态＝客户付款完成 + 平台对账完成；两侧叫法：平台侧显示「已收款」、客户侧显示「已付款」，中间状态两侧一致）
采购订单 · 支付状态：待支付 → 部分支付 → 全额支付 → 已收款（终态）
步 节点 客户侧 平台侧 单据 / 状态
1 节点 A
预付款		 采购订单详情页 → 新建采购订单 → 【提交订单】 销售订单详情页 → 自动生成平台销售订单
平台侧出现【预收款】按钮 → 平台点击 →【选择是否要预付款】
① 需要：填写预付款比例 →【生成预付款结算单】
→ 销售 / 会计【内部审核】→【推送到客户】
② 不需要：不生成结算单，直接进入下一步		 客户采购订单：草稿（客户提交后）
平台销售订单：已生成
预付款结算单：草稿 → 待审核 → 已审核 → 待付款（不设置预付款时无此单据）
平台采购订单支付状态：待支付
2 采购订单详情页 / 我的账单 → 查看结算单 → 在线支付（通联）预付款金额 → 支付完成 【预收款】按钮所在卡片 / 结算单详情 实时刷新结算单状态
 预付款结算单：待付款 → 已收款（终态，客户侧显示“已付款”）
平台采购订单支付状态：待支付 → 部分支付（预付款已收款、尾款未收）
3 预付款支付完成后进入订单履约：等待发货 / 收货 销售 / 会计核对收款 →【对账完成】→ 预付款结算单置为已收款 预付款结算单：已收款（终态，客户侧显示“已付款”）
平台采购订单支付状态：部分支付（预付款已收款、尾款未生成）
业务状态：待发货
5 节点 B
尾款		 采购订单详情页 / 我的账单 → 查看尾款结算单 全部确认收货后，平台侧出现【尾款】按钮 → 平台点击 →【生成尾款结算单】
→ 销售 / 会计【内部审核】→【推送到客户】		 尾款结算单：草稿 → 待审核 → 已审核 → 待付款
平台采购订单支付状态：部分支付（维持不变，预付款已收款、尾款未收款）
6 足额：支付待付金额
少付：填写差异原因 + 上传凭证附件 + 支付		 收到差额 →【标记差额】→【对账完成】 尾款结算单：待付款 → 已收款（终态，足额与少付均合并跳到终态；客户侧显示“已付款”）
平台采购订单支付状态：已收款（终态，两份结算单都已收款时同步触发）
7 查看尾款结算单 → 已付款（终态） 对账完成 → 采购订单结清 尾款结算单：已收款（终态，客户侧显示“已付款”）
平台采购订单支付状态：已收款（终态）
业务状态：已结清

二、平台 ↔ 供应商 · 支付节点对照（平台付款给供应商）

供应商结算与平台审核 ＋ 平台付款与供应商收款 平台 → 供应商
步 节点 供应商侧 平台侧 单据 / 状态
1 节点 C
结算与审核		 客户确认收货后 → 销售订单 → 【创建结算】→ 生成草稿结算单 —（平台此时未介入） 供应商结算单：草稿
2 核对金额、维护账单日期 → 【推送到平台】 会计 > 供应商 > 账单 出现待处理记录 供应商结算单：待审核账单
3 —（供应商不参与开票，只等收款） 会计 账单详情 → 【平台审核】→ 账单进入「已审核」，可推送付款单 供应商结算单：待审核账单 → 已审核
4 节点 D
平台付款与收款		 等待付款（结算单显示“待收款”） 账单页维护支付人 → 【推送付款单】→ 推给平台出纳
支付节点从这一步开始		 供应商结算单：待付款（供应商侧显示“待收款”）
平台采购订单支付状态：待支付
5 等待付款到账 出纳 上传支付凭证 → 【支付】→ 维护日记账、供应链金融票据 → 【创建付款】 供应商结算单：已付款（供应商侧显示“已支”）
平台采购订单支付状态：部分支付 / 全额支付
6 结算单显示“已支”，可查看支付凭证 / 付款单详情 → 确认收款 与供应商对账 → 结算单置为终态 供应商结算单：已收款（终态）
平台采购订单支付状态：已付款（终态）
业务状态：平台采购订单 / 供应商销售订单 → 已完成
