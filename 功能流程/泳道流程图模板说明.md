# 海赋泳道流程图模板

## 用途与参考

- **视觉母版**：[竞价主流程-平台自采补充版.html](竞价主流程-平台自采补充版.html)。它是本次用户确认的最终效果，不因创建模板而改动。
- **可复用空白模板**：[泳道流程图模板.html](泳道流程图模板.html)。复制该文件并只修改其中 `flow` 数据，可生成同一视觉系统的其他业务流程图；可直接下载 SVG 或打印为 PDF。
- 输出应是可编辑、可在本地打开的 HTML 流程图，不以截图替代源文件。

## 下次用户只需提供的信息

用户不需要给坐标、颜色、节点类型或连接线语法。最简输入：

> 终端：客户端、平台端、供应商端。客户端：发布需求、查看结果；平台端：审核需求、发通知；供应商端：查看需求、提交报价。关系：客户端提交后平台审核，通过后供应商报价，截止后客户端选择结果。

可以用自然语言补充条件、并行、驳回返回、定时提醒和结束状态。不强求用户先写成流程图。仅当缺失的信息会改变业务结果或权限时再提问；其余布局由制图者整理。

## 从输入到输出的整理步骤

1. **定泳道**：按实际操作主体列出终端，一端一泳道。系统自动通知作为独立泳道；如无自动动作可省略。多角色共用一端时优先同泳道，通过节点副标题标明角色，不凭空增加终端。
2. **定节点**：把每端功能转为动作、判断、状态、通知四种节点。节点名称尽量用“动词＋对象”或明确状态，短句为主；补充条件写副标题或右侧说明卡片，不挤在节点中。
3. **定关系**：先按触发顺序串联主路径，再补充跨端交接、条件分支、并行、驳回回路、定时提醒、终态。每条线必须有明确起点和终点；判断分支需标“是/否”或业务条件。
4. **定坐标**：同一阶段的跨端动作尽量并列；时间自上而下；主路径保持垂直；跨端交接使用水平或正交折线。回路用虚线，避免穿过节点、文字或其他箭头。
5. **定说明区**：与主路径无关但必须理解的排名、权限、状态规则放在右侧卡片。说明区不代替主路径，不把未确认规则写成既定规则。
6. **校验**：检查每个节点的进入与离开关系、跨端责任、分支归并、通知时点、结束状态，以及图文是否一致；再检查脚本语法和实际显示。

## 固定视觉规范

| 项目 | 模板值与规则 |
| --- | --- |
| 页面 | 白色背景；标题居中、25 px；图与说明分开，横向可滚动、可打印 |
| 泳道 | 每列约 190 px；整体浅黄色 `#fff2cc`；细边框/分隔线 `#d9a835`；标题行约 34 px |
| 节点 | 默认宽 124 px、高 43 px；圆角 5 px；边框 1.1 px；同类节点在同一端保持一致 |
| 客户/采购方 | 浅橙底 `#fff0e0`、橙边 `#efa727` |
| 平台 | 浅绿底 `#dcf0d9`、绿边 `#6db75b` |
| 供应商 | 浅蓝底 `#dfebff`、蓝边 `#7ba6ed` |
| 系统通知 | 浅红底 `#ffded8`、红边 `#eb7671` |
| 填写/提交 | 可用浅紫底 `#efe9ff`、紫边 `#a48adf` |
| 中性/汇合 | 浅灰米色 `#f5f2eb`、灰边 `#bdbab1` |
| 字体 | `Arial, PingFang SC, Microsoft YaHei, sans-serif`；泳道名 14 px 加粗（长名称可缩为 12 px）；节点主文案 14 px；副标题 10 px；说明卡片标题 18 px、正文 14 px |
| 连接线 | 深灰黑 `#222`、1.4 px，终点空心箭头；主流程实线，条件跳转/返回/旁支可用 `4 3` 虚线；以水平、垂直的正交折线为主 |
| 判断 | 菱形；分支条件应贴近对应连线，不能把两条路径混成一条 |
| 说明卡片 | 白底、浅灰边 `#ccc`；用于规则、排名或状态，不与泳道节点混用 |

这些参数取自本次竞价流程图；新图可随终端数量扩展画布，但不应随意换色、加粗连接线或改变整体排版语言。

## 模板数据约定

在 `泳道流程图模板.html` 的 `flow` 对象中：

- `terminals`：按显示顺序列出终端。每项含唯一 `id`、显示 `label`、配色 `kind`。系统通知不是用户终端，可按需添加。
- `nodes`：每项含唯一 `id`、所属 `lane`、纵向 `y`、`label`。可选 `subtitle`、`kind`、`shape:'diamond'`、`width`、`height`。
- `connections`：每项含 `from`、`to`。跨端、回路或并列关系较复杂时，提供 `via:[[x,y],...]` 定义正交折点；`dashed:true` 表示虚线；可提供 `label` 与标签坐标。
- `panels`：右侧说明卡片，按需填写 `title` 与 `rows`。不需要时可设为空数组。
- `caption`：图下阅读说明，只描述已经确认的流程口径。

模板中的示例数据仅用于展示填写方式，不是业务规则。生成具体业务图时，应替换示例节点、连接和说明，不能把示例流程保留在成品中。

## 输出验收

- 节点数量、泳道责任与用户输入一致；没有擅自添加审核或结束分支。
- 关系能从起点走到终点；跨端箭头不会穿过无关节点；提醒节点与实际时间位置并列或明确标注触发点。
- 文案、颜色、字体、连线与上述视觉母版一致；窄屏可横向滚动，放大后文字仍清晰。
- HTML 本地打开无外部依赖；SVG 可下载；脚本语法与节点引用检查通过。
